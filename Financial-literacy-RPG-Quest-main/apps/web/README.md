💰 Financial Literacy RPG

A gamified full-stack web application designed to teach financial literacy through an engaging RPG-style experience. Users complete quests, earn XP and gold, level up, and compete on a leaderboard.

---

🚀 Features

- 🔐 User Authentication (JWT-based login system)
- 🎯 Daily Quest System
- 📈 XP-based Leveling System
- 🏆 Leaderboard Ranking
- 💰 Gold Rewards
- 📊 XP Progress Bar
- 🎮 Gamified Learning Experience

---

🛠 Tech Stack

- Frontend: React (Vite)
- Backend: Node.js + Express
- Database: MySQL
- Authentication: JWT

▶️ How to Run

1️⃣ Clone the repository

git clone https://github.com/YOUR_USERNAME/financial-literacy-rpg.git
cd financial-literacy-rpg

2️⃣ Start Backend

cd apps/api
npm install
node src/server.js

3️⃣ Start Frontend

cd apps/web
npm install
npm run dev
